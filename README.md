## 🤖 Featured Engineering Projects

Here are some of the engineering projects I have designed, developed, simulated, or worked on.

### 1. Crop Scanner – Mobile Edge-AI Agricultural Rover

**An intelligent agricultural rover for offline cassava leaf disease detection.**

Crop Scanner combines mobile robotics, computer vision, and Edge AI to support agricultural disease detection, particularly in areas with limited or no internet connectivity.

**Key technologies:**
- Raspberry Pi 4
- ESP32
- Python
- Computer Vision
- Edge AI
- Embedded Systems

**System architecture:**
- Raspberry Pi 4 handles computationally intensive computer vision and AI inference.
- ESP32 handles real-time motor control, interrupts, and PWM.
- The system uses a split-brain processing architecture to separate high-level intelligence from low-level real-time control.
- AI inference is performed locally, allowing offline operation.

**Repository:** [Mobile Edge-AI Agricultural Rover](https://github.com/Bonaventure129/Mobile-edge-AI-powered-agricultural-rover-)

### 2. Bonabot – Autonomous Mobile Robot

A mobile robotics development project focused on mechanical design, ROS 2 integration, simulation, and autonomous navigation.

**Key technologies:**
- ROS 2 Jazzy
- Gazebo
- RViz2
- URDF
- SolidWorks
- Raspberry Pi
- RPLIDAR A1
- MPU6050
- DC gear motors

**Key implementations:**
- Mechanical design and 3D modelling in SolidWorks.
- CAD-to-URDF conversion.
- Robot simulation in Gazebo.
- Robot visualization in RViz2.
- Sensor integration and robot description.
- Autonomous navigation and localization experiments.

**Navigation and control experiments:**
- Dijkstra global path planning.
- A* Manhattan heuristic.
- A* Euclidean heuristic.
- AMCL localization.
- Pure Pursuit path tracking.
- PD control.

### 3. Fitxn – Smart Gym Access Control System

**Key features:**

The project combines embedded hardware, authentication, access management, and connected device technologies.
